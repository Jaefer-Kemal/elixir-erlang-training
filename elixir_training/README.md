# Elixir training

This folder contains Elixir learning examples and applications:

- Root `.ex` files are small examples covering geometry, processes, servers,
  persistence, and todo-list development.
- `todo/` is the basic Todo Mix application.
- `todo_cache/` extends the Todo application with caching, persistence, and
  process-management examples.

Run a Mix application from its own directory with `mix test` or `mix run`.
